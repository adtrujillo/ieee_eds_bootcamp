# Crea tus chips!

Este es el repositorio para el taller de la Escuela de Verano IEEE EDS, "Advanced Integrated Circuit Design: From Devices to Silicon", para aprender sobre el flujo RTL2GDS con LibreLane.
 
Aprenderás a utilizar las herramientas IIC-OSIC-TOOLS y a configurar LibreLane, depurar diseños, conocer el flujo de diseño ASIC e implementar un chip.

## Laboratorios

- [Lab 1](./lab1/complete_flow.md): Implementa un flujo de diseno con un contador.
- [Lab 2](./lab2/librelane_steps.md): Conoce la lista de todos los pasos y ejecuta un flujo interactivo.
- [Lab 3](./lab3/make_your_design.md): Controla el flujo, establece variables para diseno avanzado
- [Lab 4](./lab4/lab4.md): Exporta un diseno!
